# Whisky&Cling v0.4.4

## 安装包内容

- macOS 14+、Apple Silicon 原生 App。
- Whisky / Cling 共 6 套内置九动作素材：写实、黑白手绘、彩色漫画。
- 雅思高频单词 3,674 个，含已有音标和例句；另含少量英日语示例词。
- Chrome 插件：完整包和 App 内均附带，并另提供独立 ZIP。
- petctl、Codex skill 安装脚本、使用说明和配置截图。

## 本版更新

- 经典漫画、童话绘本双主题，重启保持选择。
- 网页选词小加号与就地词卡，不再新开表单页面。
- 工具栏弹窗固定 380px，内容过长内部滚动；加号缩小并居中。
- 桌面复习卡保持尺寸与居中操作区，气泡显示时暂停位置移动。
- DeepSeek 补全失败仍保留本地释义、原句与来源，并明确提示 HTTP 错误；重试保留语境。
- 官方 DeepSeek 默认模型改为 deepseek-flash，保留第三方服务的自定义配置。
- Key 保存状态只查询元数据，不因解密密钥而阻塞配置界面。

## 使用与限制

解压完整包并打开 App。Chrome 扩展管理开启开发者模式，加载包内 ChromeExtension 文件夹；从 App 的词典学习页复制配对码。更新插件后重新加载扩展，并刷新已打开的网页。

升级不覆盖已有素材权重和学习记录。内置素材首次运行从包内安装，不需联网。主题与宠物造型独立；绘本插画不是新的九动作动画包。

包内不包含个人设置、API Key、配对码、生词收藏或学习记录。部分词条仍缺少英美分区音标或例句译文，可自行配置有效 Key 按需补全。此前真实补全请求返回 HTTP 401；有效 Key 下的生成成功没有计入本版验证通过项。

App 为 ad-hoc 签名，未做 Apple Developer ID 公证；只提供 Apple Silicon，不包含 Intel 版。
