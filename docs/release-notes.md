## 本版更新

- 语境说明使用与词卡正文一致的只读富文本，点击选择不改变字体与段落；气泡内容不再沿用桌宠拖动状态。
- 内置 sample 可移除、重启保持隐藏，学习记录保留；“模板与格式”提供恢复入口，恢复不覆盖同 ID 导入词典。
- 词典卡片统一尺寸，改名和分类使用独立编辑弹窗，保留搜索、筛选和分页。
- 默认移动节奏减慢为短距离慢移、长时间休息，支持最低 0.05x；闲置精灵动作增加停留，运行帧率仍约 6.25fps。
- 右键菜单增加配置中心、暂停/继续走动入口，与设置页保持一致。
- 配置中心区分本机数据与演示数据；README 改为带示例截图的用户安装和使用指南。

- 配置中心预览跟随彩色漫画 / 黑白手绘 / 写实原版选择，三款主题均展示实际已启用素材。
- 内置示例可移除和恢复；导入词典确认后移到系统废纸篓，失败会提示，学习记录默认保留。

- 桌宠视觉统一为轻量半透明表面、柔和阴影与细边线，移除厚重气泡外框和三角尾巴；经典漫画、童话绘本原有主题保留。
- 点击反馈使用内容自适应小提示，宠物与提示靠近摆放；宠物统一为 128pt，呼吸幅度减弱，原生精灵动画保持约 6.25fps。
- AI 通知按来源与会话合并，最多展示三条轻通知，独立自动消失；完成通知仍优先于词汇。
- 单词保留词典式排版、双语例句、音标、回忆模式与反馈；回忆状态按内容收紧，揭示释义后在同一卡片展开，主题切换和同一状态的译文刷新保留尺寸。
- 配置中心使用更克制的标题、按钮与导航选中态；不迁移、覆盖或清空现有词库及学习记录。

- 右键桌宠先显示“单词”菜单项，选择后才学词；支持双指点按及 Control + 左键，取消菜单不会触发词卡，不影响左键互动和拖动。
- 手动学词不受自动限频和时段限制；已有词卡不重复，AI 通知优先，通知结束后响应排队的手动请求。

- 桌宠词卡改为词典式排版：单词与发音、词性与释义、双语例句、语境说明分层左对齐，例句中的目标词高亮。
- 保留回忆模式与学习反馈，揭示后平稳展开，长内容内部滚动，同一状态刷新保留阅读位置。
- 英美音标按已有标签显示，不伪造缺失音标或翻译；词条与学习记录不变。

- 词汇学习分为“我的生词 / 词典库 / 学习计划”，配对与 Key 集中到“连接与 AI”。
- 生词与词典提供后台搜索、多条件筛选、排序、可调每页数量与页码跳转；生词详情单独展示语境和学习记录。
- 只调整展示与查询，不迁移、不清空已有词条、语境、学习记录及学习设置。

- 每日自动展示和每日新词取消 50/20 硬上限，支持任意有效整数与独立“不限制”开关。
- 可配置最短弹出间隔，默认 5 分钟；不限量、重启和调整配置后仍遵守间隔。既有数量、学习时段和学习记录保持不变。

- 经典漫画、童话绘本、森林漫步三款主题，重启保持选择。
- 网页选词小加号与就地词卡，不再新开表单页面。

- 桌面复习卡保持尺寸与居中操作区，气泡显示时暂停位置移动。
- DeepSeek 补全失败仍保留本地释义、原句与来源，并明确提示 HTTP 错误；重试保留语境。

- Key 保存状态只查询元数据，不因解密密钥而阻塞配置界面。

## 使用与限制

解压完整包并打开 App。Chrome 扩展管理开启开发者模式，加载包内 ChromeExtension 文件夹；从 App 的“词汇学习 -> 连接与 AI”复制配对码。更新插件后重新加载扩展，并刷新已打开的网页。

升级不覆盖已有素材权重和学习记录。内置素材首次运行从包内安装，不需联网。主题与宠物造型独立；绘本插画不是新的九动作动画包。

包内不包含个人设置、API Key、配对码、生词收藏或学习记录。部分词条仍缺少英美分区音标或例句译文，可自行配置有效 Key 按需补全。此前真实补全请求返回 HTTP 401；有效 Key 下的生成成功没有计入本版验证通过项。

App 为 ad-hoc 签名，未做 Apple Developer ID 公证；只提供 Apple Silicon，不包含 Intel 版。
