# PetPetKnows Extension Logo

Selected direction: B, a happy white cat holding an open jade book.

The master `petpetknows-reading-cat.png` was created with the built-in image
generation tool. Brief: preserve the B composition; simplify the silhouette for
small toolbar sizes; opaque white cat, charcoal outlines, jade book, coral ears
and bookmark; transparent exterior; no lettering or floating decorations.

The extension consumes RGBA PNG exports at 16, 32, 48 and 128 pixels under
`ChromeExtension/icons/`. The popup uses the 128-pixel export at 34 CSS pixels.
The macOS app icon is intentionally unchanged.
