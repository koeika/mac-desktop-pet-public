# Whisky & Cling companions

Original package sources supplied by the pet owner:

- Whisky: https://codex-pets.net/#/pets/whisky
- Cling: https://codex-pets.net/#/pets/cling

The original manifests and nine-row spritesheets are preserved as separate pets.
The `whisky-ink` and `cling-ink` sheets are AI-assisted monochrome adaptations
created for this app from those references. Each has four frames per action and
nine action rows: idle, right walk, left walk, wave, jump, failed, waiting,
working, review. They are not a single sequential GIF.

Installation is local, idempotent, and never overwrites existing pet preferences.
Deleting an included pet persists across launches. Selecting its style explicitly
restores missing included pets. No remote download is required at launch.
